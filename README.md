# Content-to-Knowledge Operations Skill

将非结构化内容转化为可验证、可检索、可关联、可持续维护的知识资产。

## 这是什么

这是一个通用的内容知识处理工作流，适用于书籍、教材、网页、报告、视频、播客、会议记录、用户访谈和企业内部资料。

它不把 AI 输出当成最终事实，而是执行：

```text
内容接收
  -> 预处理与来源登记
  -> 结构拆解
  -> 概念、观点、证据抽取
  -> 多来源重合/增量/冲突分析
  -> 结构化知识卡
  -> 人工确认与来源追溯
  -> 检索复用
  -> 持续维护
```

## 它解决什么问题

资料越来越多，但常见的痛点是：

- 长内容难以快速理解；
- 视频、播客和文章之间无法对照；
- 看过的内容以后找不到；
- AI 总结没有来源，事实、观点和推测混在一起；
- 一次性笔记不能沉淀成团队可复用资产。

这个 Skill 的核心价值不是“生成摘要”，而是把内容加工成**可以被验证、再次找到、继续组合和持续维护的知识单元**。

## 可复用范围

流程和模板不绑定任何行业。知识源可以替换成：

- 品牌与产品资料；
- 用户研究、评论和访谈；
- 竞品报告与行业报告；
- 培训课程、会议记录和 FAQ；
- 书籍、教材、视频和播客。

本项目曾用个人学习资料验证过流程，但对外不把心理学、营养学或 AI 知识当成产品边界，也不包含私人求职、赚钱或创业资料。

## 快速使用

1. 先确认输入来源、授权范围和目标问题。
2. 选择一种输出：内容卡、概念卡、观点卡、对比卡、视频/播客卡或维护报告。
3. 按 [`SKILL.md`](SKILL.md) 执行处理流程。
4. 使用 [`templates/`](templates) 中的模板生成初稿。
5. 检查来源、事实/观点区分和不确定项。
6. 人工确认后，才写入目标知识库。

## 三个演示入口

| 演示 | 体现的能力 |
| --- | --- |
| 长文本转概念卡 | 长文本拆解、概念抽取、来源追溯 |
| 多来源对比卡 | 重合、增量、冲突和证据对齐 |
| 视频/播客分析卡 | 转写、时间戳、观点分析和待验证项 |

示例见 [`examples/`](examples)，模板见 [`templates/`](templates)，完整流程见 [`docs/workflow.md`](docs/workflow.md)。

## 面向珀莱雅的迁移方式

如果输入替换为品牌资料、产品资料、用户反馈、达人内容或竞品报告，输出可以变成：

- 产品知识卡；
- 用户需求与痛点卡；
- 竞品对比卡；
- 内容选题卡；
- 培训知识卡；
- 待验证的用户洞察。

这不是声称已经处理过珀莱雅内部数据，而是展示一套可以迁移的 AI 内容处理方法。

## 诚实边界

- AI 只生成初稿，最终知识资产需要人工确认。
- 没有转写文本或字幕时，不承诺自动理解音视频。
- 不把全文关键词搜索包装成向量检索。
- 不复制未授权的书籍、视频或播客原文，只保留必要的摘要、出处和时间戳。
- 不输出健康诊断、治疗建议或其他超出资料范围的结论。
