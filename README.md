# Content-to-Knowledge Operations Skill

将非结构化内容转化为可验证、可检索、可关联、可持续维护的知识资产。

## 这是什么

这是一个通用的内容知识处理工作流，适用于书籍、教材、网页、报告、视频、播客、会议记录、用户访谈和企业内部资料。

它不把 AI 输出当成最终事实，而是执行：

```text
内容接收
  -> 预处理与来源登记
  -> 结构拆解
  -> 概念、观点、证据抽取
  -> 多来源重合/增量/冲突分析
  -> 结构化知识卡
  -> 人工确认与来源追溯
  -> 检索复用
  -> 持续维护
```

## 它解决什么问题

资料越来越多，但常见的痛点是：

- 长内容难以快速理解；
- 视频、播客和文章之间无法对照；
- 看过的内容以后找不到；
- AI 总结没有来源，事实、观点和推测混在一起；
- 一次性笔记不能沉淀成团队可复用资产。

这个 Skill 的核心价值不是“生成摘要”，而是把内容加工成**可以被验证、再次找到、继续组合和持续维护的知识单元**。

## 可复用范围

流程和模板不绑定任何行业。知识源可以替换成：

- 品牌与产品资料；
- 用户研究、评论和访谈；
- 竞品报告与行业报告；
- 培训课程、会议记录和 FAQ；
- 书籍、教材、视频和播客。

本项目强调通用的内容知识处理方法，而不是绑定到某个行业、某个个人学习库或某个企业场景。

## 快速使用

1. 先确认输入来源、授权范围和目标问题。
2. 选择一种输出：内容卡、概念卡、观点卡、对比卡、视频/播客卡或维护报告。
3. 按 [`SKILL.md`](SKILL.md) 执行处理流程。
4. 使用 [`templates/`](templates) 中的模板生成初稿。
5. 检查来源、事实/观点区分和不确定项。
6. 人工确认后，才写入目标知识库。

## 三个演示入口

| 演示 | 体现的能力 |
| --- | --- |
| 长文本转概念卡 | 长文本拆解、概念抽取、来源追溯 |
| 多来源对比卡 | 重合、增量、冲突和证据对齐 |
| 视频/播客分析卡 | 转写、时间戳、观点分析和待验证项 |

示例见 [`examples/`](examples)，模板见 [`templates/`](templates)，完整流程见 [`docs/workflow.md`](docs/workflow.md)。可参考的说明文档见 [Markdown 版说明](docs/interview-guide.md)。

## 适用场景

如果输入替换为品牌资料、产品资料、用户反馈、内容创作素材或竞品报告，输出可以变成：

- 产品知识卡；
- 用户需求与痛点卡；
- 竞品对比卡；
- 内容选题卡；
- 培训知识卡；
- 待验证的洞察与研究问题。

这展示的是一套可迁移的 AI 内容处理方法，而不是绑定到某一家公司或某一段个人经历。

## 诚实边界

- AI 只生成初稿，最终知识资产需要人工确认。
- 没有转写文本或字幕时，不承诺自动理解音视频。
- 不把全文关键词搜索包装成向量检索。
- 不复制未授权的书籍、视频或播客原文，只保留必要的摘要、出处和时间戳。
- 不输出健康诊断、治疗建议或其他超出资料范围的结论。

## 关联案例

本 Skill 可在不同资料源中验证，例如书籍、报告、用户访谈、视频转写和行业资料。源内容不会复制进本仓库；公开仓库只保留通用的流程说明、模板和示例。当前仓库本身是可直接查看的公开作品主链接。

## 隐私与公开边界

本仓库仅保留通用的 Skill 说明、模板和示例，不包含：

- 本地工作目录、用户路径或机器环境信息；
- 个人联系方式、私密笔记或未授权资料；
- 需要保密的内部文档或未授权原文。

如果需要在公开场景中展示具体案例，建议只保留脱敏后的知识卡、结论和来源索引。
